ИНСТРУКЦИЯ

Как всё провести

  1. Скачайте сайт и загрузите только файл index.html в свой хостинг.
  2. Вставьте ссылку на опубликованный сайт в поле слева.
  3. Распечатайте билеты в двустороннем режиме на A4.
  4. Раздайте по одному каждому участнику.
  5. Сканируйте QR камерой телефона. Один билет — победный.
💡 Важно
После создания нового набора обязательно снова скачайте и загрузите файл index.html — иначе новые билеты не будут распознаны.
🖨️ Для точного совпадения сторон
При печати выберите двустороннюю печать и, если есть выбор, переворот по длинной стороне. Для ручной двусторонней печати сначала напечатайте лицевые страницы, затем вставьте листы обратно и напечатайте оборотные.
🔒 Не публикуйте файл организатораВ нём хранится полный список исходных билетов. На общедоступный сайт загружайте только index.html. Повторное сканирование одного и того же QR снова показывает тот же результат.
